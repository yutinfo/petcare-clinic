## 2. โครงหน้าจอและเส้นทาง

```
src/app/(staff)/[branch]/settings/…     ← คอนโซลของคลินิก (มี branch ใน URL เสมอ)
src/app/(platform)/admin/…              ← คอนโซลแพลตฟอร์ม (ไม่มี tenant context)
```

**ตัดสินใจ:** คอนโซลของคลินิกอยู่ใต้ `[branch]` แม้บางหน้าจะมีผลทั้ง tenant เพราะเซสชันพนักงาน
ผูกกับสาขาอยู่แล้ว ([src/middleware.ts](../src/middleware.ts) + `DEV_TENANT_SLUG`) การแยก route group
ใหม่ต้องทำ tenancy อีกชุดโดยไม่ได้อะไรเพิ่ม — ชดเชยด้วยกติกาข้อ 3 ด้านล่าง

**ทุกหน้าในคอนโซลนี้ต้อง**

1. เป็น Server Component + Server Action ตาม [AGENTS.md §6](../AGENTS.md) — ตรรกะอยู่ใน `src/modules/<domain>/` เท่านั้น
2. ตรวจสิทธิ์ด้วย `ctx.can(...)` ทั้งตอนอ่านและตอนเขียน ไม่ใช่แค่ซ่อนปุ่ม
3. ติดป้ายระดับผลกระทบที่หัวเรื่อง: 🏢 **มีผลทุกสาขา** หรือ 📍 **เฉพาะสาขานี้**
4. แสดง "แก้ล่าสุดโดย … เมื่อ …" จาก `AuditLog` และเขียน `AuditLog` ทุกการเปลี่ยนแปลง พร้อม `before` / `after` / `reason`
5. ใช้รูปแบบเดียวกันทุกหน้า: ตารางรายการ + ช่องค้นหา + แผงแก้ไขด้านข้าง + ปุ่มบันทึกที่ยืนยันซ้ำเมื่อกระทบเงิน/สต็อก/สิทธิ์
6. เงินแสดงเป็นบาททศนิยม 2 ตำแหน่ง แต่รับ-ส่งเป็นสตางค์ ([§3 ข้อ 1](../AGENTS.md)) · วันที่แสดงเป็น พ.ศ.

### ADM-05 เลขที่เอกสาร (อ่านอย่างเดียว)

แสดง `DocumentSequence` ทุก `docType` × `period` พร้อม `lastNumber` และเวลาอัปเดตล่าสุด

**ไม่มีปุ่มแก้ ไม่มีปุ่มรีเซ็ต ไม่มีการตั้งเลขเริ่มต้นจากหน้าจอ** — เลขจองในทรานแซกชันเดียวกับการออกบิลเท่านั้น
([§3 ข้อ 4](../AGENTS.md)) หน้านี้มีไว้**ตรวจความต่อเนื่อง**: ถ้าเลขขาดช่วง ต้องลิงก์ไปหาบิลที่ถูกยกเลิกในช่วงนั้นได้

### ADM-08 ตรวจภาษีทั้งแค็ตตาล็อก 🎯 หน้าที่ปลดล็อก Q2/Q6

หน้าสำหรับผู้ทำบัญชี ใช้ตอน go-live และทุกครั้งที่กฎภาษีเปลี่ยน

- ตารางเดียวรวม `ServiceItem` + `Product` ทุกแถว: ชื่อ · ประเภท · ราคา · `taxCode` ปัจจุบัน · ใครยืนยันล่าสุด
- ตัวกรองที่ต้องมี: **"ยังไม่มีคนยืนยัน"**, ตามชนิด (`ProductType` / `ServiceCategory`), ตาม `taxCode`
- แก้ `taxCode` ได้ทีละแถวและแบบเลือกหลายแถว พร้อมช่องเหตุผลครั้งเดียวต่อการบันทึก
- แถบสรุปด้านบน: จำนวนรายการแยกตาม `taxCode` ใช้กระทบยอดกับรายงานภาษีขาย
- คำเตือนค้างบนหน้าจนกว่าจะปิดประเด็น: **สินค้ากลุ่ม `DRUG` / `VACCINE` / `FOOD` ยังรอผู้ทำบัญชียืนยันเรื่อง ม.81(1)** ([docs/06 §6.2](06-billing-pos-and-tax.md), Q6 ใน [STATUS §3](STATUS.md))
- บันทึก "ใครยืนยัน เมื่อไร" รายรายการ เพื่อตอบผู้สอบบัญชีได้ว่าคนเป็นผู้ตัดสิน ไม่ใช่ระบบเดาเอง ([AGENTS.md §8](../AGENTS.md))
